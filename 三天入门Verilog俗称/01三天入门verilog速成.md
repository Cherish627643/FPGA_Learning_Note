# Verilog 三天入门 - Day 1 笔记

---

## 一、模块结构（Module Structure）

Verilog 代码的基本单元是**模块（module）**，其基本结构如下：

```Verilog
module <模块名>(<端口列表>);
    // 端口方向声明
    // 参数声明
    // 功能描述
    //      - 内部信号声明
    //      - assign 语句
    //      - initial / always 语句
    //      - 底层模块/原语调用
    //      - 任务和函数定义
endmodule
```

> - `module ... endmodule`：**必须写**
> - 模块名、端口列表、端口方向声明：**必须写**
> - 功能描述部分中最常用的只有三种语句：`assign`、`always`、底层模块调用
> - 这三种语句**与顺序无关**

---

### 示例 1：二选一数据选择器（MUX2_1）

电路功能：三个输入 `A、B、S`，一个输出 `Y`：
- 当 `S = 0` 时，`Y = B`
- 当 `S = 1` 时，`Y = A`

Verilog 描述：

```Verilog
module mux2_1(A, B, S, Y);
    input  A, B, S;
    output Y;
    assign Y = S ? A : B;
endmodule
```

> **说明**：这里使用了 `assign` 连续赋值语句与三目运算符 `?:`，中间必须是等号 `=`（连续赋值用 `=`，过程赋值用 `<=`）。

---

### 示例 2：边沿 D 触发器（DFF）

```Verilog
module DFF(clk, D, Q);
    input  clk, D;
    output reg Q;

    always @(posedge clk)
        Q <= D;
endmodule
```

> - 当 `clk` 的**上升沿**到来时执行赋值，把 `D` 赋给 `Q`
> - 端口方向声明：`input` / `output` / `inout` 三种
> - 数据类型常用 `wire` 和 `reg` 两种
> - 位宽表示：`[N1:N2]`，例如 `[3:0]` 表示 4 位

---

## 二、模块说明部分详解

### 1. 模块名
- 指电路的名字，由用户指定
- **最好与文件名一致**（Quartus II 等 EDA 工具调试时需要）

### 2. 端口列表
- 电路的输入输出信号名称列表，信号名由用户指定
- 各名称间用**逗号**隔开

### 3. 端口方向声明
说明每个端口信号的属性：
- 方向：`input` / `output` / `inout`
- 数据类型：`wire` 或 `reg`
- 位宽：`[N1:N2]`

### 4. 参数声明
说明参数的名称和数值。

### 示例：全加器（Full Adder）的端口声明

```Verilog
module for(A, B, Cin, S, Cout);
    input  [3:0] A, B;
    input        Cin;
    output [3:0] S;
    output       Cout;
endmodule
```

- 位宽若不做说明，**默认为 1 位**
- 数据类型若不做说明，**默认为 wire 类型**

---

## 三、连续赋值语句（assign）

`assign` 被称为**连续赋值语句**，是最常用的语句之一。

**基本格式**：
```Verilog
assign <赋值目标> = <表达式>;
```

**示例**：
```Verilog
assign Y = A;
assign Y = A & B;
```

### 特点
1. **始终处于激活状态**：只要表达式中任意操作数发生变化，立即重新计算并赋值
2. 对应的另一类语句是**过程赋值语句**（`always`）
3. **赋值目标必须是 `wire` 类型**

> `wire` 表示电路中的**连线**（导线），只要一端逻辑变化，传出去的信号会立即变化。`wire` 是默认类型，所以不写数据类型时自动就是 `wire`。

---

## 四、`wire` 与 `reg` 的区别

| 类型 | 含义 | 赋值方式 | 备注 |
|------|------|---------|------|
| `wire` | 电路中的连线（线网类型） | 必须用 `assign` | 默认类型 |
| `reg` | 寄存器类型 | 必须用 `always` 块内过程赋值 | 需手动声明 |

> 如果要用 `always` 语句对信号赋值，必须先将其声明为 `reg` 类型。

## 五、表达式与运算符

### 1. 算术运算符

| 运算符 | 说明 |
|--------|------|
| `+ - * /` | 加减乘除，操作数可为实数或整数 |
| `%` | 求余，操作数**只能是整数** |
| `**` | 求幂，结果取**第一个操作数的符号** |

**示例**：
```
Y  = 5 % 2;        // 结果为 1（5 = 2*2 + 1）
Y2 = 2 ** 3;       // 2 的 3 次方 = 8
```

---

### 2. 逻辑运算符

| 运算符 | 说明 |
|--------|------|
| `&&` | 逻辑与 |
| `||` | 逻辑或 |
| `!`  | 逻辑非 |

**运算结果**：1（逻辑真）、0（逻辑假）、X（不确定）

**核心规则**：
- 操作数可以是任意表达式，结果被当作逻辑值处理
- 只有 1、0、X 三种情况
- 表达式最好加括号

**关于非零即真的处理**：
> 结果只有 1/0/X 三种情况。如果结果既不是 0 也不是 X，那就当作逻辑 1。
> 例如：`2 + 3 = 5`，5 不是 0 也不是 X，所以逻辑上是 1。

**示例**：
```
3 > 2          → 1（真）
!(3 > 2)       → 0
2 < 3 && 5 > 6 → 0（一个为假，结果为假）
2 < 3 || 5 > 6 → 1（一个为真，结果为真）
```

**含 X 的情况**：
- 逻辑运算中只要有一个操作数为 X，结果通常为 X
- 例外（逻辑非）：若真值对 X 取何值都不改变结果，则结果为确定值
  - 例如：`1 || X`，X 当 0 是 1，当 1 还是 1，所以结果是 1

**示例**：
```
(2 + 3) && (3 - 3)   // 5 && 0 → 1 && 0 → 0
```

---

### 3. 关系运算符

| 运算符 | 说明 |
|--------|------|
| `>` `<` `>=` `<=` | 大于、小于、大于等于、小于等于 |

**运算结果**：1（真）、0（假）、X（不确定）

**示例**：
```
3 > 2     → 1
3 < 2     → 0
3 >= 2    → 1
3 <= 2    → 0
3 <= X    → X（无法确定）
```

---

### 4. 等价运算符

| 运算符 | 说明 |
|--------|------|
| `==` `!=` | 等于、不等于：遇 X/Z 时结果为 X |
| `===` `!==` | case 等 / case 不等：X/Z 当作确定值参与比较，必须完全相同 |

> **`===` 的含义**：将 X 视为变量，只有两边每一位完全一样时结果才为 1。

**示例**：
```
3 == 2          → 0
3 != 2          → 1
3 == 3          → 1
3 == X, 3 != X  → X, X（因为含 X）

3 === 3          → 1（两边完全一样）
3 === 4'b0011    → 1（完全一样）
```

---

### 5. 按位运算符

| 运算符 | 说明 |
|--------|------|
| `~` | 按位非，单操作数 |
| `&` `|` `^` `~^` `^~` | 按位与/或/异或/同或 |

**规则**：
- 操作数可以是 1 位或多位二进制数
- 按位非：单操作数，对每一位取反
- 按位运算（其他）：两个操作数对应位两两运算
- 位宽不同时，**短的自动在左边补 0 补齐**
- 结果的位宽与操作数位宽相同

**示例**：
```
~4'b1001       → 4'b0110

4'b1011 & 4'b0111
→ 0101 & 0111  → 0101   // 注意：短的补齐后运算

4'b1011 | 4'b0111
→ 0101 | 0111  → 0111

4'b1011 ^ 4'b0111
→ 先算与后: ~(0101 & 0111) = ~0101 = 1010
→ 再与原数算与: 1010 & 0101 = 0000
```

---

### 6. 归约运算符（缩减运算符）

**说明**：
- 单操作数
- 将该数的各位**自左至右**进行逻辑运算
- 结果只有 **1 位**

**示例**：
```Verilog
&4'b1001
→ 1 & 0 = 0
→ 0 & 0 = 0
→ 0 & 1 = 0
最终结果为 0

~|4'b1001   → 先归约与得到 0，再取非 → 1
```

---

### 7. 移位运算符

**格式**：`操作数 >> n` 或 `操作数 << n`

| 类型 | 行为 |
|------|------|
| 逻辑左移 `<<` | 右边补 0 |
| 逻辑右移 `>>` | 左边补 0（不考虑符号位） |
| **算术右移 `>>>`** | **保留符号位**，左边补符号位的值（仅对有符号数自动补符号位） |
| 算术左移 `<<<` | 左边补 0 |

**示例**：
```Verilog
4'b1001 >> 1      → 0'b0100（逻辑右移，左补 0）
4'b1001 >>> 1     → 1'b1100（算术右移，左补符号位 1）
```

> 弹幕补充："逻辑右移就是不考虑符号位，右移一位，左边补零即可。算术右移需要考虑符号位，右移一位，若符号位为 1，就在左边补 1；否则，就补 0。"

---

### 8. 拼接复制运算符

**格式**：`{拼接项1, 拼接项2, ...}`

**示例**：
```Verilog
{1'b1, 4'b0001}              → 5'b10001（贪吃蛇式拼接）
{4{1'b0}}                    → 4'b0000（4 个 0 拼接）
{4{1'b0}, 2'b11}             → 6'b000011（末尾追加 11）
```

---

### 9. 条件运算符（三目运算符）

**格式**：`表达式 ? 值1 : 值2`

> - 当 `?` 前为真（即为 1）时，结果取 `:` 前面的值
> - 当 `?` 前为假（即为 0）时，结果取 `:` 后面的值
> - 当 `?` 前为 X 时，结果为 X

**示例**：
```Verilog
assign Y = S ? A : B;       // S=1 时 Y=A，S=0 时 Y=B
```

---

### 10. 嵌套条件运算符

通过多个 `?:` 嵌套实现"多路选择"，例如 4 选 1：

```Verilog
assign Y = S1 ? (S0 ? D3 : D2) : (S0 ? D1 : D0);
```

展开逻辑：
- `S1 = 1` 且 `S0 = 1` → `Y = D3`
- `S1 = 1` 且 `S0 = 0` → `Y = D2`
- `S1 = 0` 且 `S0 = 1` → `Y = D1`
- `S1 = 0` 且 `S0 = 0` → `Y = D0`

> **弹幕补充**：条件运算符中按位计算时，某些式子如 `~ & A` 实际结果应为 0，需要注意归约与按位的区别。

## 七、弹幕中有价值的补充与勘误

| 主题 | 内容 |
|------|------|
| 数据字宽表示 | `1'bx` 表示一个 1 位宽的二进制未知值；`4'b1010` 中 4 表示位宽，b 表示二进制（binary），后面是数值 |
| `===` 含义 | x 视为变量，`===` 视为"恒等于"，必须每一位完全相同才为 1 |
| 算术右移 | 符号位要一起移动，左边补上符号位；符号位为 1 补 1，为 0 补 0 |
| `wire` 本质 | 说白了就是一根导线，导线一端逻辑变化，传出去的信号马上跟着变化 |
| `reg` 本质 | 寄存器类型，必须用过程块（`always`/`initial`）赋值 |
| 逻辑判断 | 1 代表所有不为 0 的数，所以 `3` 在逻辑运算中等价于 1 |
| 逻辑与中 X 的特例 | 如 `1 || X`，X 取 0 或 1 都得 1，结果为 1；只有两种可能结果不一致时才为 X |
