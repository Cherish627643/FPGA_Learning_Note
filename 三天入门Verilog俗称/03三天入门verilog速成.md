## 一、数据类型

Verilog 数据类型分为两大类：**线网类（net）** 和 **变量类（variable）**。

由于 **连续赋值语句** 和 **过程赋值语句** 的激活特点不同，所以赋值目标特点也不同：

- **连续赋值**：不需要保存
- **过程赋值**：需要保存

### 1. net 类型

主要用于 `wire`（线型）。其他 net 类型（如 `tri`、`wand` 等）实际开发中几乎不会出现，了解即可。

> `wire` 表示物理连线，由其所连接的器件输出连续驱动。

### 2. variable 类型

| 数据类型 | 说明 | 常见程度 |
|---|---|---|
| `reg` | 寄存器型 | ★★★ 最常用 |
| `integer` | 整型 | 较少 |
| `time` | 时间型 | 很少 |
| `real` | 实型 | 很少 |
| `realtime` | 实时间型 | 很少 |

**结论**：重点掌握 `wire` 和 `reg` 即可。

### 3. 定义成 wire 还是 reg 的决定因素

1. **使用何种赋值语句**
   - 连续赋值 / 门级赋值 / 初始化语句赋值 → 定义为 `wire`
   - 过程赋值（`always` 块内）→ 定义为 `reg`
2. **端口信号规则**
   - `input` 信号 → 必须是 `wire` 类型
   - `output` 信号 → 可以是 `wire` 或 `reg`，取决于如何赋值
   - `inout`（双向端口） → 必须是 `wire` 类型

> 弹幕补充：`output` 类型默认为 `wire`。

### 4. 典型示例分析

```verilog
// 例：D 和 E 有 3 种赋值方法

// ① 连续赋值 assign
assign D = A & B;
assign E = B | C;
// D 和 E 必须定义成 wire 型

// ② 门级赋值（实例化与门/或门）
and (D, A, B);
or  (E, B, C);
// D 和 E 都定义成 wire 型

// ③ 过程赋值 always
always @(*) begin
    D = A & B;
    E = D | C;
end
// D 和 E 必须定义成 reg 型
```

**端口示例**：

```verilog
module example(A, B, SO, CO, D, E);   // 输出端口 SO、CO 等
input  wire  A, B;
output wire  SO;     // 连续赋值 → wire
output reg   CO;     // always 块内赋值 → reg
output wire  D;
output reg   E;
```

## 二、数字表示格式

### 1. 基本格式

```
<位宽>'<进制字母><数字>
```

- **位宽**：表示数据的位数（如 `2` 表示 2 位，`10` 表示 10 位）
- **进制字母**
  - `b` / `B`：二进制 binary
  - `d` / `D`：十进制 decimal
  - `o` / `O`：八进制 octal
  - `h` / `H`：十六进制 hexadecimal

### 2. 示例

| 写法 | 含义 |
|---|---|
| `2'b00` | 2 位二进制，值为 0 |
| `5'd8` | 5 位十进制 8，等于二进制 `1000` |

### 3. 有符号数表示

```
<位宽>'s<进制><数字>
```

例如 `8'sb1011_1011`：

- 第一位是**符号位**（1 表示负数）
- 数据有效位只有 6 位（因为最高位是符号）
- 有效数据位是 `11_1011`
- 转十进制 = **-69**

> 弹幕补充：补码 `10111011` → 减一取反得到原码 `10000101` = -69。  
> 注：`111011` 的无符号十进制值是 59（不是有符号数）。

### 5. 无符号数

无符号数没有符号位，所有位都表示数据。例如 `8'b10111011` 转十进制 = **187**。

## 三、逻辑值

Verilog 中只有 **4 种** 逻辑值：

| 值 | 含义 |
|---|---|
| `1` | 逻辑 1 / 高电平 |
| `0` | 逻辑 0 / 低电平 |
| `x` / `X` | 不确定（unknown） |
| `z` / `Z` | 高阻态（high impedance） |

## 四、if 条件语句

`if` 语句是 C 语言 `if` 的扩展，共有 **4 种形式**：

### 形式 1：基本 if
```verilog
if (条件表达式)
    语句1;
```

### 形式 2：if-else
```verilog
if (条件表达式)
    语句1;
else
    语句2;
```

### 形式 3：多分支 if
```verilog
if (条件表达式1)
    语句1;
else if (条件表达式2)
    语句2;
else if (条件表达式3)
    语句3;
```

### 形式 4：带默认分支
```verilog
if (条件表达式1)
    语句1;
else if (条件表达式2)
    语句2;
else if (条件表达式3)
    语句3;
else
    默认语句;
```

### 条件判断规则

- 若条件表达式结果为 **真（1 或非零值）** → 执行 `if` 语句
- 若结果为 **零 或 x** → 执行 `else` 语句

例如 `if (1 + 2)` 结果是 3，判定为真 → 执行 if 分支。

### 多个语句必须用 begin/end 包裹

```verilog
if (条件) begin
    语句1;
    语句2;
end
```

## 五、if 语句设计组合电路的陷阱

### 陷阱：不完整条件会综合出**锁存器（latch）**

```verilog
// 错误示例：不完整条件
always @(*) begin
    if (sel)
        Q = A;     // sel=0 时 Q 保持原值 → 产生 latch
end
```

### 解决方法

**方法 1**：补全 else 分支

```verilog
always @(*) begin
    if (sel)
        Q = A;
    else
        Q = B;
end
```

**方法 2**：给 Q 设初值（消除锁存器原理）

```verilog
always @(*) begin
    Q = B;          // 先赋默认值
    if (sel)
        Q = A;
end
```

> 弹幕补充：「综合出寄存器」即指当 if 条件不满足时，电路会使用上一次的值，从而形成**锁存器状态**，应在设计中避免。

## 六、条件表达式

### 格式与规则

```verilog
<计算表达式>
```

- 条件表达式可以是任意形式的表达式
- 结果只有两种：`0` 或 `1`
- **值为 0 → 条件为假；其他情况 → 条件为真**

### 示例分析

```verilog
// 设 A = 4'b1000, B = 4'b0110
```

| 条件表达式 | 运算过程 | 真假值 |
|---|---|---|
| `A == B` | 8 ≠ 6，结果为 0 | 假（0） |
| `A > B`  | 8 > 6，结果为 1 | 真（1） |
| `A < B`  | 8 < 6，结果为 0 | 假（0） |
| `A * B`  | 8×6=48，但只取 4 位，高 2 位被截掉，结果为 0000 | 假（0） |
| `A \|\| B` | 逻辑或，4 ≠ 0 且 6 ≠ 0 | 真（1） |
| `A \| B`  | 按位或：`1000 \| 0110 = 1110`（非零） | 真（1） |

### 重点区分

- `==`（两个等号）：**等于**（逻辑判断）
- `=`（一个等号）：**赋值**操作符
- `||`：逻辑或
- `|`：按位或（对应位分别进行或运算）

> 注意：`A * B` 时 A 和 B 均为 4 位，未定义位宽则默认为 4 位，**高位会被截断**，结果恰好全为 0（弹幕笑称「两个非零数乘完竟然是 0 很可惜」）。

## 七、计数器实例

```verilog
always @(posedge clk) begin
    if (!rst)
        Q <= 0;
    else
        Q <= Q + 1;
end
```

**逻辑说明**：
- 时钟上升沿触发
- 复位信号有效（`rst=0`）时，Q 清零
- 否则 Q 加 1

## 八、综合应用：用 if 设计四选一数据选择器

弹幕提示可用 if 语句实现四选一数据选择器（典型应用场景）：

```verilog
always @(*) begin
    case (sel)
        2'b00: Q = D0;
        2'b01: Q = D1;
        2'b10: Q = D2;
        2'b11: Q = D3;
    endcase
end
```
