状态机就是数字电路里的“流程控制”。它根据**当前状态**和**输入**，决定**下一个状态**和**输出**。在 Verilog 里，状态机通常写成：

> **状态寄存器 + 次态逻辑 + 输出逻辑**

状态寄存器是唯一保存“当前状态”的地方，通常由时钟沿驱动。

---

## 1. 两种基本类型：Moore 和 Mealy

### Moore 型
输出只与**当前状态**有关。

```verilog
输出 = f(当前状态)
```

特点：
- 输出稳定，通常不会随输入立刻变化。
- 输出会晚一个周期，或者持续整个状态周期。
- 组合输出仍可能有毛刺，但比 Mealy 好控制。

### Mealy 型
输出与**当前状态 + 输入**都有关。

```verilog
输出 = f(当前状态, 输入)
```

特点：
- 响应快，可能提前一个周期输出。
- 输入变化会直接传到输出，容易有毛刺。
- 如果输入是异步或按键，通常要同步、消抖后再用。

### 混合型
部分输出 Moore，部分输出 Mealy。实际设计常见。

## 2. 状态编码方式

状态可以用不同编码表示：

| 编码 | 特点 | 适用 |
|---|---|---|
| 二进制 | 状态少，触发器少，但译码逻辑复杂 | 状态少、面积敏感 |
| 格雷码 | 相邻状态只变一位，低功耗 | 低功耗设计 |
| 独热码 one-hot | 每个状态一个触发器，译码简单，速度快 | FPGA 常用 |
| 综合器自动编码 | 写代码时不用关心，综合器选 | 一般 RTL |

写 RTL 时建议用 `localparam`：

```verilog
localparam IDLE = 3'd0,
           S1   = 3'd1,
           S2   = 3'd2;
```

不要直接用数字 0、1、2，否则代码难维护。

## 3. 推荐写法：三段式状态机

三段式最清晰，也最符合硬件结构：

1. **第一段：时序逻辑，更新当前状态**
   - 用非阻塞赋值 `<=`
   - 复位时进入初始状态
2. **第二段：组合逻辑，计算次态**
   - 用阻塞赋值 `=`
   - 用 `case` 描述状态转移
3. **第三段：输出逻辑**
   - 组合输出用 `=`
   - 需要无毛刺可用时序输出 `<=`

模板：

```verilog
// 第一段：状态寄存器
always @(posedge clk or negedge rst_n) begin
    if (!rst_n)
        state <= IDLE;
    else
        state <= next_state;
end

// 第二段：次态组合逻辑
always @* begin
    next_state = state; // 默认保持，防止 latch
    case (state)
        IDLE: begin
            if (start) next_state = RUN;
            else       next_state = IDLE;
        end
        RUN: begin
            if (done) next_state = IDLE;
            else      next_state = RUN;
        end
        default: next_state = IDLE;
    endcase
end

// 第三段：输出逻辑
always @* begin
    out = 0; // 默认值，防止 latch
    case (state)
        RUN: out = 1;
        default: out = 0;
    endcase
end
```

关键点：
- 状态寄存器用 `<=`，因为它是触发器。
- 次态和输出组合逻辑用 `=`，因为它们是数据流。
- 不要在同一个 always 里混用 `=` 和 `<=`。
- 组合逻辑必须给默认值，否则会综合出锁存器。

## 4. 完整例子：检测输入序列 1011

下面是一个 Moore 型三段式状态机，检测 `1011`，支持重叠。

状态定义：
- `IDLE`：初始
- `S1`：已收到 `1`
- `S10`：已收到 `10`
- `S101`：已收到 `101`
- `S1011`：已收到 `1011`，输出 1

```verilog
module seq_detect_1011 (
    input  wire clk,
    input  wire rst_n,
    input  wire in,
    output reg  out
);

localparam IDLE  = 3'd0,
           S1    = 3'd1,
           S10   = 3'd2,
           S101  = 3'd3,
           S1011 = 3'd4;

reg [2:0] state, next_state;

// 第一段：状态寄存器
always @(posedge clk or negedge rst_n) begin
    if (!rst_n)
        state <= IDLE;
    else
        state <= next_state;
end

// 第二段：次态组合逻辑
always @* begin
    next_state = state; // 默认保持
    case (state)
        IDLE:  next_state = in ? S1 : IDLE;
        S1:    next_state = in ? S1 : S10;
        S10:   next_state = in ? S101 : IDLE;
        S101:  next_state = in ? S1011 : S10;
        S1011: next_state = in ? S1 : S10; // 重叠处理
        default: next_state = IDLE;
    endcase
end

// 第三段：Moore 输出
always @* begin
    out = 0;
    case (state)
        S1011: out = 1;
        default: out = 0;
    endcase
end

endmodule
```

如果写成 Mealy，输出可以提前：

```verilog
// Mealy：在 S101 且 in=1 时立刻输出 1
always @* begin
    out = 0;
    case (state)
        S101: if (in) out = 1;
        default: out = 0;
    endcase
end
```

Mealy 响应快，但 `in` 的毛刺会直接传到 `out`。

## 5. 一段式、两段式、三段式

| 写法 | 特点 | 建议 |
|---|---|---|
| 一段式 | 状态、次态、输出全在一个 always | 简单状态机可读，复杂时容易乱 |
| 两段式 | 状态寄存器 + 组合次态和输出 | 常用，但输出和次态混在一起 |
| 三段式 | 状态、次态、输出分开 | 最推荐，清晰、易综合、易验证 |

初学建议直接掌握三段式。

## 6. 常见坑

1. **状态寄存器用 `=`**
   - 错误：`state = next_state;`
   - 应：`state <= next_state;`
   - 否则当前状态立即变化，可能让后续逻辑看到新状态。

2. **组合逻辑没有默认值**
   - 会综合出锁存器。
   - `next_state = state;` 和 `out = 0;` 是好习惯。

3. **没有 `default`**
   - 非法状态可能无法恢复。
   - `default: next_state = IDLE;` 更安全。

4. **输出直接组合，毛刺传到外面**
   - 如果输出要干净，加一级寄存器：
   ```verilog
   always @(posedge clk or negedge rst_n) begin
       if (!rst_n) out_r <= 0;
       else        out_r <= out;
   end
   ```

5. **Mealy 输入未同步**
   - 异步输入直接进 Mealy 输出，会有毛刺和亚稳态风险。
   - 先做两级同步器。

6. **多个 always 驱动同一个状态或输出**
   - 禁止。一个信号只能在一个 always 中赋值。

7. **状态编码随意改**
   - 用 `localparam`，不要手写魔法数字。

## 7. 状态机设计步骤

1. 明确输入、输出、时钟、复位。
2. 列出所有状态，写清每个状态含义。
3. 画状态转移图或状态表。
4. 选择 Moore / Mealy。
5. 选择编码：二进制、独热码、格雷码。
6. 用三段式写 Verilog。
7. 仿真：复位、正常转移、边界输入、非法状态。
8. 综合后检查面积、时序、是否产生 latch。

---

## 8. 一句话总结

> 状态机就是“当前状态 + 输入 → 次态 + 输出”。  
> 状态寄存器用 `<=`，次态和输出组合逻辑用 `=`，推荐三段式：状态、次态、输出分开写。  
> Moore 输出稳，Mealy 响应快；组合输出防毛刺，时序输出最干净。
